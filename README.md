# Séance 6 — TP guidé : Gestionnaire de tâches

Ce projet React/Vite est la **correction du TP guidé uniquement**.

## Fonctionnalités présentes
- Affichage de trois tâches initiales
- Ajout de tâches avec formulaire contrôlé
- Refus des tâches vides ou composées d'espaces
- Réinitialisation du champ après ajout

## Fonctionnalités à réaliser ensuite ensemble (non implémentées)
- Cocher/décocher une tâche
- Compter les tâches terminées
- Filtrer les tâches
- Supprimer une tâche

## Démarrage
```bash
npm install
npm run dev
```

L'état est uniquement en mémoire : un rechargement réinitialise les tâches.
